# Рейтинг эффективности транспорта

## Назначение

Отдельная страница **«Эффективность ТС»** внутри действующего портала Arvento:

- UI: `GET /efficiency`;
- справочники: `GET /api/efficiency/options?date_from=YYYY-MM-DD&date_to=YYYY-MM-DD`;
- запуск фонового расчёта: `POST /api/efficiency/jobs` с JSON-параметрами;
- статус, результат и Excel: `GET /api/efficiency/jobs/{id}`,
  `GET /api/efficiency/jobs/{id}/result`, `GET /api/efficiency/jobs/{id}/excel`.

Период ограничен **31 календарным днём** для защиты основного PostgreSQL от тяжёлых запросов. Одновременно выполняется не более одного GPS-анализа; ещё один может ожидать. Готовый результат и Excel живут в памяти процесса 30 минут, не записываются в базу. При перезапуске портала расчёт надо запустить заново.

Портал наследует существующий защищённый путь Nginx; прямой доступ к порту приложения извне не предусмотрен. Старый пункт «Эффективность легкового транспорта» сохранён и не изменяет свой формат.

## Источники и определения

1. **Сводный отчёт:** `consolidated_report_cache`. Пробег внутри/снаружи берётся из готового кэша, не пересчитывается по GPS при открытии страницы.
2. **Разнарядка:** актуальная на конкретный день запись из `consolidated_roster_snapshots` / `consolidated_roster_entries`. День считается плановым только для машины из разнарядки и только с понедельника по пятницу. В выборку включаются и машины с нулевыми показателями.
3. **GPS:** `gps_points` по нормализованному госномеру за каждый день в `Europe/Istanbul`. Здесь рассчитываются движение внутри площадки, длительность стоянок, переходы через границу, внешние поездки и подтверждённые превышения.
4. **Граница Аккую:** действующий полигон `SITE` PostGIS. Он используется **всегда**, даже если дополнительные зоны пока не нарисованы.
5. **Офисные стоянки:** выбираемые полигоны `OFFICE` (новый тип в редакторе), `PARKING` или `WORK_ZONE`. Если ни один не выбран, длительность стоянок не рассчитывается и соответствующий компонент рейтинга отключён.
6. **Разрешённые зоны:** выбранные активные полигоны PostGIS. Если список пуст, использование вне выбранных зон не рассчитывается и не влияет на рейтинг.
7. **Выходные:** суббота и воскресенье. Работа на площадке подтверждается хотя бы одним интервалом движения внутри полигона в такой день, не одним фактом входа в геозону.

### Интервалы GPS

- Движение — две последовательные точки внутри `SITE`, обе со скоростью свыше 3 км/ч и интервалом не более 5 минут.
- Стоянка у выбранного офиса — непрерывная серия точек внутри зоны со скоростью от 0 до 3 км/ч. Полная продолжительность засчитывается **строго при превышении** заданного минимума (по умолчанию более 5 минут). Разрыв между соседними GPS-точками свыше 15 минут завершает серию без домысливания времени.
- Внешние поездки — подтверждённое время движения и ориентировочный пробег Arvento `distance_km` для точек вне всех выбранных разрешённых зон. Некорректные/слишком большие приращения отбрасываются. Пробег вне зон — оценка по GPS, а не бухгалтерский показатель.
- Обед — отдельные счётчики выхода из `SITE` и повторного входа в заданные окна. Их наличие/отсутствие **не штрафуется автоматически**.

### Скорость

- Пороги по умолчанию — **50 км/ч внутри** и **103 км/ч снаружи**. Пользователь может изменить оба порога.
- Минимальная продолжительность по умолчанию — **3 секунды**, но в любом случае необходимы **не менее трёх** последовательных скоростных GPS-точек.
- Используется действующая защита от одиночных скачков и физически неправдоподобного ускорения.
- Каждая действующая геозона `SPEED_EXCLUSION` / `TUNNEL` автоматически прерывает скоростной эпизод и не учитывается как превышение. Классификация на площадке / снаружи — по текущему полигону `SITE`.
- Выводятся количество подтверждённых событий внутри и снаружи, интервал, максимум скорости, порог и ссылка на координаты события.

## Рейтинг

Базовые веса:

| Критерий | Вес | Расчёт |
| --- | ---: | --- |
| Дни с нормой пробега внутри | 50% | Дни `inside_km ≥ норматив` / плановые будни в разнарядке |
| Движение / (движение + офисные стоянки) | 25% | Подтверждённые GPS-минуты |
| Доля внутри Аккую | 15% | `inside_km / (inside_km + outside_km)` |
| Использование в разрешённых зонах | 10% | `1 − min(1, км вне зон / общий км)` |

Норматив по умолчанию: Ford Transit / Ford Transıt (в т.ч. турецкое написание `TRANSİT`) — **50 км/день**, остальные модели — **30 км/день**.

Если офисные/разрешённые зоны ещё не выбраны, соответствующие веса **исключаются** и сумма оставшихся нормируется до 100%. Такой балл явно помечается **предварительным**; отсутствие геозон не считается нулевой эффективностью.

К базовому баллу применяется штраф за подтверждённую скорость: **−3 балла за эпизод, максимум −15**, затем результат ограничивается 0–100. Обед и выходные отображаются отдельно и на балл не влияют.

Если нет GPS за период, плановых рабочих дней или актуального сводного кэша хотя бы за один запрошенный день, балл — **Н/Д**, машина остаётся в таблице без места в рейтинге. Актуальность сверяется штатным механизмом водяных знаков `load_cache_coverage`, а не только флагом `SUCCESS`. Текущие сутки всегда помечаются предварительными.

## Фильтры и экспорт

Доступен множественный выбор госномеров, дирекций, пользователей и марок/моделей, диапазон дат, два обеденных окна, два порога пробега, минимальная стоянка, два порога скорости и длительность, а также два независимых списка геозон.

Excel содержит четыре листа: **«Рейтинг ТС»**, **«По дням»**, **«Превышения скорости»**, **«Методика»**. Низкие показатели и подтверждённые нарушения выделяются цветом. HTML-таблица содержит долю внутреннего пробега, отношение внутреннего пробега к внешнему и отношение подтверждённого движения ко времени стоянок.

## Приёмка перед публикацией

```bash
python verify_all.py --static
python verify_all.py --runtime
```

После независимого ревью желательно проверить на read-only staging с реальными GPS за 1, 7 и 30 суток: длительность выполнения, совпадение количества машин с разнарядкой, непротиворечивость пробегов и отсутствие событий скорости внутри тоннелей. Публикация на основной сервер производится **отдельным согласованным релизом**, с проверкой нагрузки и возможностью отката.
