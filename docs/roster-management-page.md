# Страница «Разнарядки»

Адрес:

```text
/rosters
```

Возможности:

- загрузка одного или нескольких файлов XLSX/XLSM;
- определение даты по имени файла или содержимому книги;
- замена сохранённой разнарядки при совпадении даты;
- список сохранённых дат, файлов и количества автомобилей;
- скачивание восстановленной из PostgreSQL копии разнарядки;
- ручной перерасчёт готовой истории за вчера и сегодня;
- переход со страницы отчётов и обратно.

Исходные бинарные файлы не сохраняются. В PostgreSQL хранятся распознанные строки разнарядки: дата, госномер, компания, пользователь и грейд. Кнопка «Скачать» формирует новую XLSX-книгу из этих данных.

## Развёртывание

```bash
cd /opt/arvento_report
git pull origin main
python3 verify_repository.py
docker compose -f docker-compose.server.yml build report-portal
docker compose -f docker-compose.server.yml up -d --force-recreate report-portal
```

Проверка маршрутов:

```bash
curl -I http://127.0.0.1:18084/rosters
curl -sS http://127.0.0.1:18084/api/rosters
```

После входа на основную страницу портала отображается ссылка `Разнарядки →`.
