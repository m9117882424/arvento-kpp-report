# Arvento KPP Reports

Набор Python-скриптов для анализа координатных выгрузок Arvento, расчёта въездов/выездов, пробега внутри и снаружи территории, стоянок по геозонам и нарушений заданной траектории движения.

## Поддерживаемые форматы

Для основных отчётов поддерживаются:

- `.xlsx`
- `.xlsm`
- `.csv`

XML пока не поддерживается.

Парсер не предполагает, что заголовки таблицы находятся в первой строке. Он последовательно ищет строку, содержащую обязательные колонки: госномер, дату/время, широту и долготу. Поэтому перед таблицей могут находиться одна, две или больше служебных строк, например название отчёта и период выгрузки.

CSV-парсер автоматически:

- определяет разделитель `;`, `,`, табуляцию или `|`;
- проверяет кодировки UTF-8 BOM, UTF-8, Windows-1251 и Windows-1254;
- ищет фактическую строку заголовков после служебных строк;
- обрабатывает десятичную запятую;
- читает файл построчно, не загружая весь CSV в оперативную память.

Excel-парсер также пропускает служебные строки перед таблицей и начинает импорт только после обнаружения фактической строки заголовков.

## Обработка больших файлов

Для крупных выгрузок данные импортируются во временную SQLite-базу.

Порядок обработки:

1. Исходный CSV или Excel читается последовательно.
2. Координатные записи пакетами записываются во временную SQLite-базу.
3. Создаётся индекс по дате, государственному номеру и времени.
4. Анализ выполняется отдельно по каждому автомобилю или дате.
5. После завершения временная база удаляется автоматически.

Для исходника размером около 600 МБ рекомендуется иметь не менее 2–3 ГБ свободного места на системном диске, поскольку временная база создаётся в каталоге `%TEMP%`.

## Реестр геозон

КПП и геозоны задаются в `geozones.json`, а не берутся из Arvento.

Раздел `gates` содержит линии КПП. Раздел `geozones` поддерживает:

- `polygon` — полигон;
- `circle` — круг.

Стоянка определяется как интервал более 10 минут между последовательными сообщениями движения. Геозона стоянки определяется по координатам до и после интервала.

## Разнарядки

Сводный отчёт автоматически ищет Excel-разнарядки (`.xlsx`, `.xlsm`, `.xls`) в папке исходной выгрузки.

Из разнарядки подставляются:

- водитель;
- грейд;
- должность;
- дирекция.

Дата разнарядки определяется из имени файла либо из первых строк книги. Для даты отчёта выбирается разнарядка с точной датой, а при её отсутствии — последняя доступная. Если разнарядки или госномера нет, соответствующие ячейки остаются пустыми.

## Сводный отчёт по КПП

Запуск с выбором исходного файла:

```powershell
python arvento_kpp_report.py
```

С явным указанием файла:

```powershell
python arvento_kpp_report.py "C:\Reports\Report.csv"
```

Создаются:

```text
Report_по_дням.xlsx
Report_итоговая_сводка.xlsx
```

Дневной отчёт содержит первый въезд, последний выезд, сведения из разнарядки, пробег, время движения и стоянок.

## Отчёт по первому въезду

Для рабочего варианта используйте:

```powershell
python arvento_first_entry_report_fixed.py
```

Или:

```powershell
python arvento_first_entry_report_fixed.py "Report_24.xlsx" "Разнарядка.xlsx" "Первый въезд.xlsx" --time-from 07:00 --time-to 09:00
```

`arvento_first_entry_report_fixed.py` использует устойчивое определение стороны линии КПП. GPS-точки в пограничной зоне не сбрасывают последнюю подтверждённую сторону автомобиля. Например, последовательность `+34,2 м → −0,56 м → −8,68 м` корректно определяется как одно пересечение.

## Отчёт о запрещённом повороте налево

Скрипт:

```text
prohibited_left_turn_report.py
```

Четыре координаты задают осевую линию линейной геозоны:

```text
1. 36.3172538740116, 33.874474367432896
2. 36.31719343922596, 33.874075574912666
3. 36.31714948662511, 33.8735029497554
4. 36.31720168033584, 33.87281614041499
```

По умолчанию:

- ширина линейной геозоны — 30 м, то есть по 15 м от осевой линии;
- нарушение фиксируется только при проходе справа налево: от точки 1 к точке 4;
- максимальное время прохода — 5 минут;
- старт должен находиться в первых 25% длины коридора;
- окончание — после 75% длины коридора;
- существенное обратное движение вправо сбрасывает незавершённый кандидат;
- защита от повторной регистрации одного манёвра — 5 минут.

Таким образом, простое нахождение автомобиля рядом с одной из координат нарушением не считается. Должен быть подтверждён направленный проход по коридору с востока на запад.

Запуск с выбором выгрузки через окно:

```powershell
python prohibited_left_turn_report.py
```

Запуск с явным указанием файла:

```powershell
python prohibited_left_turn_report.py "C:\Reports\Report.csv"
```

Изменение параметров:

```powershell
python prohibited_left_turn_report.py "C:\Reports\Report.csv" --width 30 --max-minutes 5 --cooldown-minutes 5
```

Результат создаётся рядом с исходником:

```text
Report_запрещенный_поворот.xlsx
```

Книга содержит:

- госномер;
- дату и время начала и окончания прохода;
- длительность;
- скорость в начале и конце;
- прогресс по коридору;
- минимальное отклонение от осевой линии;
- количество GPS-точек, попавших в коридор;
- фактические координаты;
- адрес начала и окончания;
- отдельный лист `Параметры` с настройками расчёта.

Подробная инструкция по первому въезду: [USER_GUIDE.md](USER_GUIDE.md).
