# Arvento KPP Reports

Набор Python-скриптов для анализа координатных выгрузок Arvento, расчёта въездов/выездов, пробега внутри и снаружи территории, а также стоянок по зарегистрированным геозонам.

## Поддерживаемые форматы

Для сводного отчёта `arvento_kpp_report.py` поддерживаются:

- `.xlsx`
- `.xlsm`
- `.csv`

XML пока не поддерживается.

CSV-парсер автоматически:

- определяет разделитель `;`, `,`, табуляцию или `|`;
- проверяет кодировки UTF-8 BOM, UTF-8, Windows-1251 и Windows-1254;
- ищет строку заголовков среди первых 100 строк;
- обрабатывает десятичную запятую;
- читает файл построчно, не загружая весь CSV в оперативную память.

## Обработка больших файлов

Для крупных выгрузок данные импортируются во временную SQLite-базу.

Порядок обработки:

1. Исходный CSV или Excel читается последовательно.
2. Координатные записи пакетами записываются во временную SQLite-базу.
3. Создаётся индекс по дате, государственному номеру и времени.
4. Анализ выполняется отдельно по каждой дате и каждому автомобилю.
5. В оперативной памяти находится только текущий трек автомобиля, а не весь исходный файл.
6. После успешного завершения временная база удаляется автоматически.

Во время выполнения отображается прогресс:

```text
Импортировано в SQLite: 500 000
Импортировано в SQLite: 1 000 000
Создание индекса SQLite...
Анализ 21.07.2026: автомобилей 95
```

Для исходника размером около 600 МБ рекомендуется иметь не менее 2–3 ГБ свободного места на системном диске, поскольку временная база создаётся в каталоге `%TEMP%`.

## Реестр геозон

КПП и геозоны задаются в `geozones.json`, а не берутся из Arvento.

Раздел `gates` содержит линии КПП. Раздел `geozones` поддерживает:

- `polygon` — полигон;
- `circle` — круг.

Пример круговой геозоны:

```json
{
  "name": "АЗС",
  "enabled": true,
  "type": "circle",
  "center": [36.1535, 33.5729],
  "radius_m": 100
}
```

Пример полигональной геозоны:

```json
{
  "name": "Бетонный завод",
  "enabled": true,
  "type": "polygon",
  "points": [
    [36.1500, 33.5500],
    [36.1500, 33.5550],
    [36.1550, 33.5550],
    [36.1550, 33.5500]
  ]
}
```

Стоянка определяется как интервал более 10 минут между последовательными сообщениями движения. Геозона стоянки определяется по координатам до и после интервала:

- обе точки в одной геозоне — высокая достоверность;
- только одна точка в геозоне — средняя достоверность;
- обе точки вне реестра — `Вне зарегистрированных геозон`.

## Запуск

С выбором исходного файла через диалог:

```powershell
python arvento_kpp_report.py
```

С явным указанием файла:

```powershell
python arvento_kpp_report.py "C:\Reports\Report.csv"
```

Файл `geozones.json` ищется сначала рядом с исходной выгрузкой, затем в каталоге программы.

## Результаты

Для исходного файла `Report.csv` создаются две книги рядом с исходником:

```text
Report_по_дням.xlsx
Report_итоговая_сводка.xlsx
```

### Книга по дням

Каждая календарная дата размещается на отдельном листе: `21.07.2026`, `22.07.2026` и т. д.

### Итоговая книга

Содержит листы:

- `Сводка по автомобилям` — показатели за весь период;
- `Сводка по дням` — показатели по автомобилю и дате;
- `Стоянки` — детализация всех интервалов стоянок;
- `Стоянки по геозонам` — количество и суммарное время по автомобилю и геозоне.

## Показатели сводного отчёта

- начало и конец периода;
- состояние в начале и конце;
- количество въездов и выездов;
- пробег внутри, снаружи и общий;
- процент пробега внутри и снаружи;
- время на территории;
- время движения на территории;
- время стоянки на территории;
- количество стоянок;
- процент движения и стоянки.
