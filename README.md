# Arvento KPP Report

Скрипт формирует Excel-отчёт по координатной выгрузке Arvento.

## Что определяет

- въезд через KPP 4 или KPP 5 с севера на юг;
- выезд через KPP 4 или KPP 5 с юга на север;
- несколько циклов въезда/выезда одного автомобиля в течение дня;
- пробег внутри территории;
- пробег снаружи территории;
- диагностические случаи: повторный въезд, выезд без найденного въезда, незакрытый период.

Отчёт группируется по государственному номеру.

## Особенности КПП

- **KPP 4 TEST**: линия определяется автоматически по медианным координатам точек геозоны.
- **KPP 5 TEST**: используется широкая линия проезда между точками:
  - `36.15886644084745, 33.549775396083724`
  - `36.159167964778234, 33.55101996362877`

## Требования

- Python 3.10+
- Windows, Linux или macOS
- исходный файл `.xlsx` или `.xlsm`

Установка:

```powershell
pip install -r requirements.txt
```

## Запуск

С выбором файла через диалог:

```powershell
python arvento_kpp_report.py
```

С указанием файла:

```powershell
python arvento_kpp_report.py "C:\Reports\arventotest.xlsx"
```

Результат сохраняется рядом с исходным файлом:

```text
arventotest_КПП_отчет.xlsx
```

## Листы отчёта

- `Сводка`
- `Проезды КПП`
- `Периоды внутри`
- `Диагностика`
- `Параметры`

## Основные входные колонки

Скрипт автоматически ищет русские, турецкие и английские варианты названий:

- госномер;
- дата/время;
- широта;
- долгота;
- одометр;
- расстояние;
- скорость;
- область/геозона;
- адрес.

## Логика пробега

Приоритет источников:

1. разница одометра;
2. поле расстояния из выгрузки;
3. GPS-расстояние между координатами.

Подозрительные скачки и нереалистичные GPS-сегменты отбрасываются.
