# Arvento KPP Report

Скрипт формирует итоговый Excel-отчёт по координатной выгрузке Arvento.

## Что рассчитывается

- въезды через KPP 4 и KPP 5;
- выезды через KPP 4 и KPP 5;
- несколько циклов въезда и выезда одного автомобиля в течение дня;
- пробег внутри территории;
- пробег снаружи территории;
- процент пробега внутри и снаружи;
- время на территории;
- время движения на территории;
- время стоянки на территории;
- процент движения и стоянки от учтённого времени на территории.

## Итоговые столбцы

1. Госномер
2. Начало периода
3. Конец периода
4. Состояние в начале
5. Состояние в конце
6. Въездов
7. Выездов
8. Пробег внутри, км
9. Пробег снаружи, км
10. Общий пробег, км
11. Пробег внутри, %
12. Пробег снаружи, %
13. Время на территории
14. Время в движении на территории
15. Время стоянки на территории
16. Движение на территории, %
17. Стоянка на территории, %

## Определение стоянки

Стоянкой считается сегмент со скоростью не более `1 км/ч`.

Разрывы между сообщениями более 5 минут не включаются во время движения или стоянки. Это предотвращает ошибочное начисление стоянки при отсутствии связи.

Пороговые значения настраиваются в начале файла:

```python
STOP_SPEED_KMH = 1.0
MAX_TIME_ACCOUNT_GAP_SECONDS = 5 * 60
```

## Особенности КПП

- **KPP 4 TEST**: линия определяется автоматически по медианным координатам точек геозоны.
- **KPP 5 TEST**: используется широкая линия между точками:
  - `36.15886644084745, 33.549775396083724`
  - `36.159167964778234, 33.55101996362877`

## Требования

- Python 3.10+
- Windows, Linux или macOS
- исходный файл `.xlsx` или `.xlsm`

Установка:

```powershell
pip install -r requirements.txt
```

## Запуск

С выбором файла через диалог:

```powershell
python arvento_kpp_report.py
```

С указанием файла:

```powershell
python arvento_kpp_report.py "C:\Reports\arventotest.xlsx"
```

Результат сохраняется рядом с исходным файлом:

```text
arventotest_КПП_отчет.xlsx
```

В книге создаётся один лист: `Итоговый отчёт`.

## Основные входные колонки

Скрипт автоматически ищет русские, турецкие и английские варианты названий:

- госномер;
- дата/время;
- широта;
- долгота;
- одометр;
- расстояние;
- скорость;
- область/геозона;
- адрес.

## Логика пробега

Приоритет источников:

1. разница одометра;
2. поле расстояния из выгрузки;
3. GPS-расстояние между координатами.

Подозрительные скачки и нереалистичные GPS-сегменты отбрасываются.
