# Arvento KPP Reports

Набор Python-скриптов для анализа координатных выгрузок Arvento по КПП 4 и КПП 5.

Въезды и выезды определяются по фактическому направлению пересечения координатных линий КПП. Наличие геозоны или её привязка к автомобилю в Arvento для основной логики не требуется.

## Скрипты

### `arvento_kpp_report.py`

Формирует сводный отчёт по использованию территории:

- количество въездов и выездов;
- пробег внутри и снаружи территории;
- доля пробега внутри и снаружи;
- время на территории;
- время движения и стоянки на территории;
- состояние автомобиля в начале и конце периода.

### `arvento_first_entry_report.py`

Формирует отчёт по первому въезду автомобилей на территорию:

- определяет въезд по пересечению координатной линии KPP 4 или KPP 5;
- выбирает первый учитываемый въезд автомобиля за день;
- подставляет модель, грейд, водителя, должность и дирекцию из Excel-разнарядки;
- поддерживает опциональный диапазон грейдов;
- поддерживает опциональный диапазон времени;
- учитывает только числовую часть грейда: `7`, `7a`, `7B` считаются грейдом `7`;
- опционально исключает въезд, если в этот же день до него уже был выезд с территории;
- может использовать отчёт «Сигнал географического региона» как резервный источник входов;
- создаёт лист `Проверка` с параметрами расчёта и причинами исключений.

Подробная пользовательская инструкция: [USER_GUIDE.md](USER_GUIDE.md).

## Требования

- Python 3.10 или новее;
- Windows, Linux или macOS;
- Excel-файлы `.xlsx` или `.xlsm`;
- библиотека `openpyxl`.

Установка зависимостей:

```powershell
python -m pip install -r requirements.txt
```

## Быстрый запуск отчёта по первому въезду

С диалоговым выбором файлов и фильтров:

```powershell
python arvento_first_entry_report.py
```

Пример: грейды с 7 по 14, время с 07:00 до 09:00, исключать повторные въезды после предыдущего выезда:

```powershell
python arvento_first_entry_report.py "Report_tsmenerji3.xlsx" "Разнарядка.xlsx" "Первый въезд.xlsx" --grade-from 7 --grade-to 14 --time-from 07:00 --time-to 09:00 --consider-previous-exits
```

С дополнительным отчётом геозон:

```powershell
python arvento_first_entry_report.py "Report_tsmenerji3.xlsx" "Разнарядка.xlsx" "Первый въезд.xlsx" --geo-events "Report_Сигнал_географического_региона.xlsx" --grade-from 7 --grade-to 14 --time-from 07:00 --time-to 09:00 --consider-previous-exits
```

## Ключевая логика отчёта по первому въезду

- **Въезд**: пересечение линии КПП с внешней стороны на внутреннюю.
- **Выезд**: пересечение той же линии в обратном направлении.
- **Учитывать предыдущие выезды**: въезд исключается, когда в этот же календарный день до него уже зафиксирован координатный выезд через KPP 4 или KPP 5.
- Событие Arvento «выход из геозоны KPP» не считается выездом с территории: оно может означать только покидание небольшой зоны вокруг ворот.
- Максимальный допустимый разрыв между GPS-точками возле КПП — 15 минут.

## Основные входные данные

### Координатная выгрузка Arvento

Скрипты автоматически ищут русские, турецкие и английские варианты колонок:

- госномер;
- дата и время;
- широта;
- долгота;
- область или геозона;
- для сводного отчёта также одометр, расстояние и скорость.

### Excel-разнарядка

Для отчёта по первому въезду используется файл с данными автомобилей и водителей. Основная обязательная колонка — госномер. Дополнительно распознаются:

- марка и модель;
- грейд;
- пользователь или водитель;
- должность;
- дирекция.

## Выходные файлы

### Отчёт по первому въезду

Создаются листы:

- `Первый въезд` — итоговый список;
- `Проверка` — применённые фильтры, статистика, отсутствующие в разнарядке госномера и въезды, исключённые из-за предыдущего выезда.

### Сводный отчёт КПП

Создаётся лист `Итоговый отчёт` с показателями пробега и времени.
