# Инструкция пользователя

## 1. Назначение

`arvento_first_entry_report.py` формирует Excel-отчёт по первому учитываемому въезду автомобилей через KPP 4 и KPP 5.

Въезд определяется по координатам GPS: скрипт проверяет пересечение линии КПП между двумя последовательными точками автомобиля. Название геозоны в Arvento для этого не требуется.

Данные водителя, автомобиля, грейда, должности и дирекции берутся из Excel-разнарядки.

## 2. Что потребуется

Подготовьте:

1. координатную выгрузку Arvento;
2. актуальную Excel-разнарядку;
3. опционально — отчёт Arvento «Сигнал географического региона»;
4. компьютер с Python 3.10 или новее.

## 3. Первичная установка

Откройте PowerShell в папке со скриптами и выполните:

```powershell
python -m pip install -r requirements.txt
```

Проверка Python:

```powershell
python --version
```

Если команда `python` не найдена, установите Python и включите опцию `Add Python to PATH`.

## 4. Самый простой запуск

В папке проекта выполните:

```powershell
python arvento_first_entry_report.py
```

Скрипт последовательно предложит:

1. выбрать координатную выгрузку Arvento;
2. выбрать файл разнарядки;
3. указать минимальный грейд;
4. указать максимальный грейд;
5. указать начальное время;
6. указать конечное время;
7. выбрать, учитывать ли предыдущие выезды.

Пустое значение в поле фильтра означает отсутствие ограничения.

Пример параметров:

- грейд от: `7`;
- грейд до: `14`;
- время от: `07:00`;
- время до: `09:00`;
- учитывать предыдущие выезды: `Да`.

## 5. Запуск с параметрами

### Одна строка

```powershell
python .\arvento_first_entry_report.py ".\Report_tsmenerji3.xlsx" ".\Разнарядка.xlsx" ".\Первый въезд.xlsx" --grade-from 7 --grade-to 14 --time-from 07:00 --time-to 09:00 --consider-previous-exits
```

### Несколько строк в PowerShell

```powershell
python .\arvento_first_entry_report.py `
  ".\Report_tsmenerji3.xlsx" `
  ".\Разнарядка.xlsx" `
  ".\Первый въезд.xlsx" `
  --grade-from 7 --grade-to 14 `
  --time-from 07:00 --time-to 09:00 `
  --consider-previous-exits
```

Символ обратного апострофа `` ` `` в PowerShell означает продолжение команды на следующей строке.

## 6. Дополнительный отчёт геозон

Отчёт «Сигнал географического региона» можно передать как резервный источник входов:

```powershell
python .\arvento_first_entry_report.py `
  ".\Report_tsmenerji3.xlsx" `
  ".\Разнарядка.xlsx" `
  ".\Первый въезд.xlsx" `
  --geo-events ".\Report_Сигнал_географического_региона.xlsx" `
  --grade-from 7 --grade-to 14 `
  --time-from 07:00 --time-to 09:00 `
  --consider-previous-exits
```

Координатное пересечение имеет приоритет. Отчёт геозон используется только для случаев, когда координатное пересечение определить не удалось.

## 7. Параметры

| Параметр | Назначение |
|---|---|
| `--grade-from 7` | минимальный грейд |
| `--grade-to 14` | максимальный грейд |
| `--time-from 07:00` | начало временного диапазона |
| `--time-to 09:00` | конец временного диапазона |
| `--consider-previous-exits` | исключать въезд, если до него в тот же день уже был выезд |
| `--no-consider-previous-exits` | явно не применять проверку предыдущих выездов |
| `--geo-events FILE.xlsx` | дополнительный отчёт геозон |
| `--no-filter-dialog` | не показывать окна фильтров |

Границы диапазонов включаются. Например, время `09:00:00` попадает в диапазон до `09:00`.

## 8. Как обрабатываются грейды

Учитывается только числовая часть:

- `7`, `7a`, `7A`, `7b` → грейд 7;
- `10`, `10a`, `10B` → грейд 10;
- `14`, `14c` → грейд 14.

Фильтр `7–14` включает все буквенные варианты этих грейдов.

## 9. Логика предыдущих выездов

При включённой опции `--consider-previous-exits` скрипт проверяет события автомобиля с начала календарного дня.

Въезд не включается в отчёт, если перед ним уже был зафиксирован выезд через KPP 4 или KPP 5.

Пример:

1. автомобиль находился внутри территории;
2. в 06:30 выехал;
3. в 07:40 въехал обратно;
4. въезд в 07:40 не считается первым прибытием на работу и исключается.

Выезд определяется по обратному пересечению координатной линии КПП. Событие «выход из геозоны KPP» для этой проверки не используется.

## 10. Результат

Если выходной путь не указан, файл создаётся рядом с координатной выгрузкой под именем:

```text
Первый въезд <имя исходного файла>.xlsx
```

В книге создаются два листа.

### `Первый въезд`

Содержит:

- номер строки;
- госномер;
- дату въезда;
- время въезда;
- ссылку на карту;
- КПП;
- марку и модель;
- грейд;
- водителя;
- должность;
- дирекцию.

### `Проверка`

Содержит:

- пути к исходным файлам;
- выбранные фильтры;
- количество найденных въездов и выездов;
- количество исключений;
- госномера, отсутствующие в разнарядке;
- автомобили, исключённые из-за предыдущего выезда;
- время предыдущего выезда и исключённого въезда.

## 11. Требования к координатной выгрузке

Скрипт автоматически распознаёт русские, турецкие и английские варианты колонок. Обязательны:

- госномер;
- дата и время;
- широта;
- долгота.

Допустимый разрыв между последовательными GPS-точками возле КПП — не более 15 минут.

Если связь отсутствовала дольше, пересечение между этими точками не интерполируется.

## 12. Требования к разнарядке

Обязательна колонка с госномером. Дополнительно могут использоваться:

- марка и модель;
- грейд;
- пользователь или водитель;
- должность;
- дирекция.

Госномера нормализуются: пробелы и разделители не влияют на сопоставление.

## 13. Типовые ошибки

### `В координатной выгрузке не найдены колонки...`

Выбран не тот отчёт или названия колонок отличаются от поддерживаемых. Нужна выгрузка с госномером, датой/временем, широтой и долготой.

### `В координатной выгрузке нет пригодных GPS-точек`

Колонки найдены, но значения координат или времени пустые либо имеют неподдерживаемый формат.

### `В разнарядке не найден столбец с госномером`

Проверьте, что выбран правильный Excel-файл разнарядки и в нём есть колонка госномера.

### Автомобиль отсутствует в отчёте

Проверьте лист `Проверка`. Возможные причины:

- грейд вне диапазона;
- время въезда вне диапазона;
- грейд не найден в разнарядке;
- до въезда уже был выезд;
- пересечение произошло при разрыве GPS более 15 минут;
- маршрут не пересёк координатную линию KPP 4 или KPP 5.

### Предупреждение `Workbook contains no default style`

Скрипт подавляет это предупреждение. Оно связано со структурой Excel-файла Arvento и не является ошибкой расчёта.

## 14. Сводный отчёт КПП

Для расчёта пробега и времени внутри/снаружи территории используется:

```powershell
python arvento_kpp_report.py
```

Или с указанием входного файла:

```powershell
python arvento_kpp_report.py "C:\Reports\arventotest.xlsx"
```

Результат сохраняется рядом с исходной выгрузкой с суффиксом `_КПП_отчет.xlsx`.
